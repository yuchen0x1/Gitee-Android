# 版本更新日志

这里是 Gitee Client 的完整版本记录。已发布条目依据对应 Git 标签之间的提交与 GitHub Release 整理；日期采用北京时间。尚未推送、发布的本地改进单独列在「未发布」，不代表历史安装包已经具备这些能力。

## [Unreleased] - 未发布

### 国际化

- 应用支持自动按 Android 系统语言选择中文或 English；无法识别时回退到简体中文。
- 个人页新增界面语言选择，选择会保存在本机并在下次启动继续生效；Gitee 内容、账号和协议字段保持原样。

## [1.4.2] - 2026-11-16

### 通知与仓库体验

- 通知中心支持「未读 / 全部」切换，分组默认展开，增加明确的标记已读入口。
- 标记已读仅在服务端成功后更新，失败会保留通知并提示；全部已读会先确认操作范围。
- 刷新失败保留已有通知，分页可重试；切换账号与处理通知后，未读计数及时刷新。
- 仓库能力中心按区块显示失败原因，部分管理接口无权限时仍可查看可访问内容。

### 编辑与恢复

- Issue / PR 编辑表单自动保存并恢复草稿，提交失败时保留输入。
- 改善代码编辑冲突提示、搜索旧请求覆盖和分页刷新恢复。
- 使用指南移除过期版本号与代码高亮说明。

### Android 更新

- 增加 APK 下载进度、大小与 SHA-256 校验，以及系统安装器交接；缺少校验值或校验失败时拒绝安装。
- 修正 Android 生物识别宿主与主题配置，以及系统安装器桥接的编译错误。
- Release 构建缺少正式签名材料时直接失败，不再回退到 Debug 签名。
- SHA256SUMS 必须按 APK 文件名唯一匹配，避免多资产发布时选错校验值。
- 更新资产优先选择通用 Android APK；只有分架构包时不会按顺序误选。
- Android 8+ 未允许安装未知来源应用时，更新对话框提供系统设置入口。

本版包含通知、草稿恢复、仓库能力中心错误隔离、更新完整性和发布安全改进。正式 Release 构建需要 GitHub Actions 注入签名密钥；真机安装和跨版本更新仍需设备验收。

## [1.4.1] - 2026-11-10

### 修复与体验

- 修复订阅仓库列表因不支持的排序参数而加载失败的问题。
- 提交列表和详情在缺少关联账号时，仍可显示提交记录中的作者姓名。
- 个人页快捷入口随屏幕宽度和系统字体大小调整，改善窄屏排版与点击反馈。
- 新手引导改用可滚动内容，改善较小屏幕和放大字体下的展示。
- 优化明暗主题下的辅助文字、图标和底部弹窗背景。
- 发布列表摘要去除 Markdown 标记，保留正文预览，完整内容仍在详情页查看。

### 安装说明

- 本版 Android 发布包由此前的 Debug 签名切换到 Release 签名，已核验 v1.4.0 与 v1.4.1 的公开 APK 证书不同。旧签名版本无法直接覆盖安装；请先备份必要信息，卸载应用会清除本地数据。

[完整变更](https://github.com/yuchen0x1/Gitee-Android/compare/v1.4.0...v1.4.1)

## [1.4.0] - 2026-11-08

### 新增

- 首次启动增加功能引导，帮助了解仓库阅读、协作和通知入口。
- 主题支持跟随系统、浅色、深色三种模式，并保存选择。
- 最近读取的仓库详情、README、文件目录和源码可在网络不可用时使用离线缓存查看，并显示缓存提示。
- 文件浏览与代码页面增加可点击的路径导航，方便返回上级目录。

### 改善

- 仓库卡片显示相对更新时间。
- 空列表增加可执行的操作入口，并补充 Issue、Star、订阅与关注等快捷入口。

离线缓存用于已读取内容的回看，不代表支持离线提交代码或同步修改。

[完整变更](https://github.com/yuchen0x1/Gitee-Android/compare/v1.3.0...v1.4.0)

## [1.3.0] - 2026-11-06

- 统一动态、仓库和个人页的明暗主题、卡片、边框与文字层级。
- 调整仓库和用户列表的头像、统计信息及排版，改善浏览时的信息区分。

## [1.2.0] - 2026-11-05

- 支持识别 Gitee 网页中的仓库、Issue、PR、提交和用户链接，并跳转到对应页面。
- 底部导航、Star 和 Issue 状态操作增加触觉反馈。
