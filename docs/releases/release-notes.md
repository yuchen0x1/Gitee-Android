# 版本更新日志

这里是 Gitee Client 的完整版本记录。已发布条目依据对应 Git 标签之间的提交与 GitHub Release 整理；日期采用北京时间。尚未推送、发布的本地改进单独列在「未发布」，不代表历史安装包已经具备这些能力。

## [1.4.4] - 2026-11-26

## 📢 版本概述

本版为仓库维护更新：补齐构建产物的忽略规则，清理重复的未发布日志，并修复普通 CI 的分析与构建配置。应用功能和本地数据格式没有变化。

## 🔧 改进与优化

- 普通 CI 对 Flutter 3.50 既有的 info 级弃用提示仍会显示，但不再因此失败；warning 和 error 仍会阻止通过。CI 构建 Android Debug APK；正式 APK/AAB 仍由 Release 工作流注入签名材料后生成。
- 补充 `android/app/build/` 和 `release-assets/` 忽略规则，避免本地构建与发布产物误加入源码仓库。
- 删除「未发布」中已在 v1.4.3 发布的多语言条目，避免把已交付功能误报为待发布内容。

## 🔒 安全与兼容性

- 修复 Android Release 构建未把正式签名配置绑定到 `buildTypes.release` 的问题；发布工作流现在会验证每个 APK 的签名，并要求证书与 v1.4.1 正式证书一致，验证失败时停止发布。
- v1.4.2、v1.4.3 的公开 APK 缺少有效签名，不能覆盖安装 v1.4.1 或其他正式签名版本；请备份必要数据后卸载旧版，再安装 v1.4.4。v1.4.0 使用 Debug 证书，同样不能直接覆盖正式签名版本。
- 本版不改变 Release 签名门禁；缺少有效签名材料时仍会拒绝生成正式包。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `gitee-client-v1.4.4-android-universal.apk` | Android 通用 | 推荐大多数 Android 设备安装 |
| `gitee-client-v1.4.4-android-armeabi-v7a.apk` | Android ARMv7 | 32 位 ARM 设备 |
| `gitee-client-v1.4.4-android-arm64-v8a.apk` | Android ARM64 | 64 位 ARM 设备 |
| `gitee-client-v1.4.4-android-x86_64.apk` | Android x86_64 | x86_64 Android 设备 |
| `gitee-client-v1.4.4-android.aab` | Android App Bundle | 应用商店或分发平台使用，不是直接安装包 |
| `SHA256SUMS.txt` | 校验文件 | 核对下载资产的 SHA-256 |

- 首次安装：下载通用 APK，并按 Android 系统提示确认安装。
- 已安装用户：应用更新检查使用 GitHub Releases；v1.4.4 高于此前正式版本，可被旧版更新检查发现。v1.4.2、v1.4.3 及使用 Debug 证书的 v1.4.0 无法直接覆盖安装，请先备份数据再卸载旧版并安装 v1.4.4；v1.4.1 使用与 v1.4.4 相同的正式证书，可直接覆盖升级。

## 🧪 验证结果

- 发布说明提取器的 Python 标准库测试：6 项通过。
- GitHub Actions 发布流程会校验版本与说明，并且仅在 Android 签名 APK/AAB 构建成功后发布。

## 🔄 升级与数据迁移

- **兼容性**：v1.4.1 使用与本版相同的正式证书，可直接覆盖升级；v1.4.2、v1.4.3 及使用 Debug 证书的 v1.4.0 需要先备份数据、卸载旧版再安装。
- **配置和数据**：没有数据格式或配置迁移；卸载应用会清除本机数据。
- **回退方式**：回退安装受 Android 版本号与签名规则限制；需要回退时先备份本地数据。

## [1.4.3] - 2026-11-17

### 国际化

- Android 应用支持按系统语言自动选择中文或 English，并在个人页手动切换和持久化。
- Flutter 系统本地化委托接入应用壳层，Gitee 内容、账号和 API 字段保持原样。

## [1.4.2] - 2026-11-16

### 通知与仓库体验

- 通知中心支持「未读 / 全部」切换，分组默认展开，增加明确的标记已读入口。
- 标记已读仅在服务端成功后更新，失败会保留通知并提示；全部已读会先确认操作范围。
- 刷新失败保留已有通知，分页可重试；切换账号与处理通知后，未读计数及时刷新。
- 仓库能力中心按区块显示失败原因，部分管理接口无权限时仍可查看可访问内容。

### 编辑与恢复

- Issue / PR 编辑表单自动保存并恢复草稿，提交失败时保留输入。
- 改善代码编辑冲突提示、搜索旧请求覆盖和分页刷新恢复。
- 使用指南移除过期版本号与代码高亮说明。

### Android 更新

- 增加 APK 下载进度、大小与 SHA-256 校验，以及系统安装器交接；缺少校验值或校验失败时拒绝安装。
- 修正 Android 生物识别宿主与主题配置，以及系统安装器桥接的编译错误。
- Release 构建缺少正式签名材料时直接失败，不再回退到 Debug 签名。
- SHA256SUMS 必须按 APK 文件名唯一匹配，避免多资产发布时选错校验值。
- 更新资产优先选择通用 Android APK；只有分架构包时不会按顺序误选。
- Android 8+ 未允许安装未知来源应用时，更新对话框提供系统设置入口。

本版包含通知、草稿恢复、仓库能力中心错误隔离、更新完整性和发布安全改进。正式 Release 构建需要 GitHub Actions 注入签名密钥；真机安装和跨版本更新仍需设备验收。

## [1.4.1] - 2026-11-10

### 修复与体验

- 修复订阅仓库列表因不支持的排序参数而加载失败的问题。
- 提交列表和详情在缺少关联账号时，仍可显示提交记录中的作者姓名。

- 新手引导改用可滚动内容，改善较小屏幕和放大字体下的展示。

- 发布列表摘要去除 Markdown 标记，保留正文预览，完整内容仍在详情页查看。

### 安装说明

- 本版 Android 发布包由此前的 Debug 签名切换到 Release 签名，已核验 v1.4.0 与 v1.4.1 的公开 APK 证书不同。旧签名版本无法直接覆盖安装；请先备份必要信息，卸载应用会清除本地数据。
