# 版本更新日志

这里是 Gitee Client 的完整版本记录。已发布条目依据对应 Git 标签之间的提交与 GitHub Release 整理；日期采用北京时间。尚未推送、发布的本地改进单独列在「未发布」，不代表历史安装包已经具备这些能力。

## [1.4.5] - 2026-11-27

## 📢 版本概述

本版修复仓库搜索、目录导航、Issue / PR 刷新、AI 摘要和 Android 在线更新中的异常场景，并加强账号切换时的会话隔离及历史明文凭证清理。应用仍仅发布 Android 版本，配置与数据格式保持兼容。

## 🔧 改进与优化

- AI 接口地址兼容尾随斜杠及已有 `/v1` 的配置；网络失败、超时及无效响应会显示可恢复提示，Issue 摘要包含正文。
- 更新下载使用独立临时目录，失败时删除未完成的安装包；正文长时间无数据时超时并按次数限制重试。
- Release 流程在构建前执行 Python 测试、Flutter 静态分析和 Flutter 回归测试；CI / Release 临时构建附件保留 7 天，正式 Release 附件不受影响。
- 清理更新日志中已经发布却重复标为“未发布”的条目。

## 🐛 问题修复

- 组织仓库搜索结果现在使用真实命名空间，避免误用创建者账号导致打开错误仓库或 404。
- 修复文件浏览器点击根目录、父目录面包屑时跳转层级偏移的问题，并同步返回历史。
- Issue / PR 刷新始终读取第一页；丢弃刷新前未完成的分页响应，避免旧评论或提交混入新列表、重复和跳页。刷新失败时保留已有内容。
- AI 摘要失败或用户先关闭加载弹窗时，不再残留加载层或误退出详情页。
- Issue / PR 页面关闭后，迟到的评论操作失败不再访问已销毁页面的提示栏。
- 更新网页兜底只识别本仓库发布链接，无法识别版本时报告检查失败；不同当前版本的并发检查不再复用已过滤的结果。
- 关闭更新对话框后，迟到的下载结果不再启动 Android 安装器。

## 🔒 安全与兼容性

- 安全存储已存在令牌或 AI Key 时，也会删除旧版 SharedPreferences 中遗留的明文副本。
- 账号失效清理按会话隔离，避免旧请求的异步清理和导航覆盖重新登录；当前令牌的存储操作按调用顺序完成。
- 正式 APK 继续要求与 v1.4.1 / v1.4.4 相同的发布证书，签名验证失败时停止发布。

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `gitee-client-v1.4.5-android-universal.apk` | Android 通用 | 推荐大多数 Android 设备安装 |
| `gitee-client-v1.4.5-android-armeabi-v7a.apk` | Android ARMv7 | 32 位 ARM 设备 |
| `gitee-client-v1.4.5-android-arm64-v8a.apk` | Android ARM64 | 64 位 ARM 设备 |

- 首次安装：下载通用 APK，并按 Android 系统提示安装。
- 已安装用户：在应用内检查更新，或打开本版 GitHub Release。Android 8+ 安装应用内下载的 APK 时，需要允许本应用安装未知来源应用。

## 🔄 升级与数据迁移

- **兼容性**：v1.4.1、v1.4.4 使用相同正式证书，可直接覆盖升级。历史记录中的 v1.4.0 使用 Debug 证书，v1.4.2 / v1.4.3 公开包缺少有效签名，不能承诺直接覆盖安装；请先备份必要信息，再按 Android 安装提示处理，卸载会清除本机数据。
- **配置和数据**：不改变数据格式；自动清理的仅为已经迁移到安全存储的旧明文凭证副本。
- **更新提示**：继续使用原 GitHub 仓库的公开稳定版 Release、`v*` 标签与通用 APK 命名，供旧版检查新版本。
- **回退方式**：受 Android 版本号与签名规则限制；回退前先备份本地数据。

## 🧪 验证结果

- 发布说明提取器的 6 项 Python 测试、132 项 Flutter 测试及静态分析门禁均通过；静态分析仍保留既有 info 级提示。
- GitHub Actions 已完成通用 APK、3 个分架构 APK 和 AAB 构建，4 个 APK 均通过正式证书检查。下载公开通用 APK 后，SHA-256 与 `SHA256SUMS.txt`、GitHub asset digest 一致，本地 `apksigner verify` 通过。
- Android 真机通过 `adb install -r` 从 v1.4.4（版本码 10）覆盖升级到 v1.4.5（版本码 11），首次安装时间保持不变；未执行卸载或清除数据。
- GitHub 稳定版 latest 已指向本版；核验网络中的匿名 API 请求触发限流时，公开 Release 网页兜底仍成功跳转至 v1.4.5。
- 真机处于锁屏状态，未核验旧版应用内更新弹窗、生物识别、真实账号操作、应用内数据内容或系统安装器交互。

## [1.4.4] - 2026-11-26

## 📢 版本概述

本版为仓库维护更新：补齐构建产物的忽略规则，清理重复的未发布日志，并修复普通 CI 的分析与构建配置。应用功能和本地数据格式没有变化。

## 🔧 改进与优化

- 普通 CI 对 Flutter 3.50 既有的 info 级弃用提示仍会显示，但不再因此失败；warning 和 error 仍会阻止通过。CI 构建 Android Debug APK；正式 APK/AAB 仍由 Release 工作流注入签名材料后生成。
- 补充 `android/app/build/` 和 `release-assets/` 忽略规则，避免本地构建与发布产物误加入源码仓库。
- 删除「未发布」中已在 v1.4.3 发布的多语言条目，避免把已交付功能误报为待发布内容。

## 🔒 安全与兼容性

- 修复 Android Release 构建未把正式签名配置绑定到 `buildTypes.release` 的问题；发布工作流现在会验证每个 APK 的签名，并要求证书与 v1.4.1 正式证书一致，验证失败时停止发布。
- v1.4.2、v1.4.3 的公开 APK 缺少有效签名，不能覆盖安装 v1.4.1 或其他正式签名版本；请备份必要数据后卸载旧版，再安装 v1.4.4。v1.4.0 使用 Debug 证书，同样不能直接覆盖正式签名版本。
- 本版不改变 Release 签名门禁；缺少有效签名材料时仍会拒绝生成正式包。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `gitee-client-v1.4.4-android-universal.apk` | Android 通用 | 推荐大多数 Android 设备安装 |
| `gitee-client-v1.4.4-android-armeabi-v7a.apk` | Android ARMv7 | 32 位 ARM 设备 |
| `gitee-client-v1.4.4-android-arm64-v8a.apk` | Android ARM64 | 64 位 ARM 设备 |
| `gitee-client-v1.4.4-android-x86_64.apk` | Android x86_64 | x86_64 Android 设备 |
| `gitee-client-v1.4.4-android.aab` | Android App Bundle | 应用商店或分发平台使用，不是直接安装包 |
| `SHA256SUMS.txt` | 校验文件 | 核对下载资产的 SHA-256 |

- 首次安装：下载通用 APK，并按 Android 系统提示确认安装。
- 已安装用户：应用更新检查使用 GitHub Releases；v1.4.4 高于此前正式版本，可被旧版更新检查发现。v1.4.2、v1.4.3 及使用 Debug 证书的 v1.4.0 无法直接覆盖安装，请先备份数据再卸载旧版并安装 v1.4.4；v1.4.1 使用与 v1.4.4 相同的正式证书，可直接覆盖升级。

## 🧪 验证结果

- GitHub Actions CI 已通过：静态分析、Python 标准库测试、Flutter 测试和 Android Debug APK 构建均成功。
- 发布说明提取器的 Python 标准库测试：6 项通过。
- 已核验公开 APK：v1.4.1 使用正式证书，v1.4.0 使用 Debug 证书，v1.4.2、v1.4.3 缺少有效签名；v1.4.4 发布流程会验证 APK 签名和正式证书指纹。

## 🔄 升级与数据迁移

- **兼容性**：v1.4.1 使用与本版相同的正式证书，可直接覆盖升级；v1.4.2、v1.4.3 及使用 Debug 证书的 v1.4.0 需要先备份数据、卸载旧版再安装。
- **配置和数据**：没有数据格式或配置迁移；卸载应用会清除本机数据。
- **回退方式**：回退安装受 Android 版本号与签名规则限制；需要回退时先备份本地数据。

## [1.4.2] - 2026-11-16

### 通知与仓库体验

- 通知中心支持「未读 / 全部」切换，分组默认展开，增加明确的标记已读入口。
- 标记已读仅在服务端成功后更新，失败会保留通知并提示；全部已读会先确认操作范围。
- 刷新失败保留已有通知，分页可重试；切换账号与处理通知后，未读计数及时刷新。
- 仓库能力中心按区块显示失败原因，部分管理接口无权限时仍可查看可访问内容。

### 编辑与恢复

- Issue / PR 编辑表单自动保存并恢复草稿，提交失败时保留输入。
- 改善代码编辑冲突提示、搜索旧请求覆盖和分页刷新恢复。
- 使用指南移除过期版本号与代码高亮说明。

### Android 更新

- 增加 APK 下载进度、大小与 SHA-256 校验，以及系统安装器交接；缺少校验值或校验失败时拒绝安装。
- 修正 Android 生物识别宿主与主题配置，以及系统安装器桥接的编译错误。
- Release 构建缺少正式签名材料时直接失败，不再回退到 Debug 签名。
- SHA256SUMS 必须按 APK 文件名唯一匹配，避免多资产发布时选错校验值。
- 更新资产优先选择通用 Android APK；只有分架构包时不会按顺序误选。
- Android 8+ 未允许安装未知来源应用时，更新对话框提供系统设置入口。

本版包含通知、草稿恢复、仓库能力中心错误隔离、更新完整性和发布安全改进。正式 Release 构建需要 GitHub Actions 注入签名密钥；真机安装和跨版本更新仍需设备验收。
